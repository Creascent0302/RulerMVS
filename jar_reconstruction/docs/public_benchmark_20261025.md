# 新公共预训练模型与baseline：公共TEST完整评测

日期：2026-10-25。**全量精度、同卡交替计时均已完成**，没有进行任何参数训练或按TEST选权重。7套固定TEST共11,970组；54组方法配置×数据集对照、87,090次模型样本评测，不是87,090个独立样本。

## 先看结论

1. 公共预训练权重在部分域具备竞争力，尚未全面超过MVSAnywhere。同像素、共享TRAIN范围对照下，自研MAE在7域中的4域较低，但Hypersim、VKITTI2、DynamicReplica仍更差；即使MAE占优，其他指标也可能不占优。
2. **搜索范围是重大混杂因素。** MatrixCity上，MVSAnywhere原生范围＋一轮细化MAE171.314m，共享与自研相同TRAIN范围后10.617m；自研原生高分辨率匹配为10.326m，共同像素为9.305m。不能把171→10的差距全部宣传为新架构优势。共享范围控制是本轮追加的诊断，不是其官方默认部署配方。
3. 原生高分辨率匹配没有普遍提高精度。MatrixCity共同像素对照反而更好，VKITTI2也略好；不能仅增加图像分辨率就假定收益。其他域存在小幅差异，详见表格。
4. CARLA微调后多数公共域指标变差，例如MatrixCity MAE10.326→61.348m。这支持保留公共预训练与CARLA适配两份权重；领域偏移/遗忘是原因假设，当前测试不能证明唯一成因。
5. 单卡5090、FP32且TF32关闭：四图单参考自研约36ms，MVSAnywhere首遍约22ms、细化版约37ms。自研没有在速度上超过首遍基线；与细化版接近，不以1ms左右的差别宣称确定的结构加速。

## 权重与协议

- 自研公共权重：`runs/active/public_pretrain_no_hero_v2/pretrained.pt`，VAL选出的阶段3第6遍；原始DA-V2编码器/ImageNet ResNet初始化后进行本地联合训练，无Hero任务参数、缓存或蒸馏。
- 自研CARLA权重：同目录`carla_finetune/pretrained.pt`，DEV选出的第58遍。额外测试其公共域保持性，不把它与公共预训练权重混为同一结果。
- MVSAnywhere：原始官方Hero完整权重；分别测试首遍、原生范围细化1轮、共享TRAIN范围后细化1轮。保留官方核心模块、标定启发式和范围更新算法；第三项只用官方显式范围接口提供已知TRAIN范围。
- Fast-MVSNet：官方DTU权重，原生稀疏估计/学习传播/GN，96深度平面；范围采用与自研相同TRAIN统计。未在这些公共数据上重新训练。
- SimpleRecon：完整官方四目结构的既有CARLA3000步权重，ImageNet初始化、四目metadata层从头训练；**不是官方八目Hero任务权重**。其MLP输入维度固定，不复制双目成四目，故两个双目域不适用。弱成绩不能作为原论文能力上限。

共同主图256×448、相同参考槽、真实N=2或4；只有自研原生匹配分支额外读同一原图独立缩放的512×896。共同像素版将256×448主图放大到既有匹配分支尺寸，不能获得额外高频像素。这会改变其训练时的输入分布，因此两个版本均报告。

精度统一FP32/TF32关闭，标签nearest-exact重采样；所有合法正深度GT与输入有效域都保留，不额外裁为2–80或仅保留候选覆盖区域。MAE/RMSE/AbsRel按有效预测像素累计；delta分母为全部有效GT，缺失预测记失败，并单列覆盖率。Fast-MVSNet极少数无效预测没有被藏掉，见coverage；其他配置覆盖率100%。低分辨率原生输出按depth_K重采样到共同图像格点。仅比较单参考深度，没有点云、占据、已验证表面或车端端到端结果。

只用TRAIN统计设置自研/Fast/Simple的范围；MVSAnywhere原生两项保留其标定启发式。追加共享TRAIN范围用于隔离已知范围信息的影响，不读取TEST深度设置范围，也不逐数据集选择最好版本来拼一个baseline。

训练预算和预训练暴露不同，这是已有权重在共同部署协议下的比较，不是同预算的纯架构消融。场景清单核对：TartanAir本地TEST2个场景均匹配官方训练场景；MVS-Synth 12个中11个、VKITTI2 10个天气序列所属场景也匹配官方训练清单。Hypersim、Blended和Dynamic存在官方validation对应。未匹配不证明未见过；DA/DINO原始预训练暴露未独立核实，不能统称zero-shot盲测。

## 验证与复现

- 新增指标/共同像素测试2项通过；全部适用组合首中尾真实样本通过。
- 第一批187分片、第二批70分片全部完成，无重复或漏掉的帧；同域所有方法GT分母一致，首/中/尾输入哈希跨两批一致。正式数据源总组数11970未变。
- 全程离线，不下载任何数据或权重，不使用本地电脑网络；所有较大结果经runs/active软链接存数据盘。本次不写逐帧深度大数组，只保存统计；结束空闲约414GiB，超过200GiB保留线。
