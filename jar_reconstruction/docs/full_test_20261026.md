# 新一轮八卡训练：完整深度精度与性能对照（2026-10-26）

## 结论

1. 本轮重训没有全面优于上一轮：原生匹配输入下，七公共域中3域MAE改善、4域变差。CARLA完整200帧MAE从2.01495变为2.23957m，缺相机150帧从1.81160变为1.92129m。当前不据此替换此前权重。
2. 对固定的MVSAnywhere共享TRAIN范围＋一轮细化对照，新自研原生输入在TartanAir、MVS-Synth、BlendedMVS的MAE较低；Hypersim、MatrixCity、VKITTI2、DynamicReplica仍较差。只给共同256×448像素后，BlendedMVS优势消失，仅TartanAir与MVS-Synth保持MAE优势。不能把额外高分辨率信息归因于纯架构。
3. 不能只看MAE：BlendedMVS新自研MAE较低，但RMSE/AbsRel/δ1均不及共享范围细化基线。MatrixCity新自研δ1相比旧模型提高，同时MAE/RMSE变差，显示阈值命中比例与大误差风险的趋势不同。
4. CARLA新自研10–24m段改善，但2–10m及24–80m段变差；完整帧远距MAE从6.2562升至7.3591m。新权重未解决远距瓶颈。更长训练/权重选择/训练轨迹变化是待隔离原因，不能仅据本次测试归罪于布局优化或断言编码器能力不足。
5. 本轮没有调整模型权重、搜索范围或超参数来追逐TEST成绩。后续改进应回到TRAIN/VAL诊断，保留本次固定对照。

6. CARLA350组按GT像素加权合并：新自研MAE2.103316m/RMSE5.948403m；旧自研1.927899/5.669520m；MVSAnywhere既有CARLA首遍1.319186/4.278576m。完整/缺失集合分别见后表。训练器BF16记录的新MAE2.102576m与此FP32结果接近，本次独立重算未发现指标累积错误。

7. 公共四目网络中位约31.8ms，双目约24.8ms；快于MVSAnywhere一轮细化，慢于首遍。四目自研独占allocated峰值约1.020GiB，对照约1.755–1.765GiB；参数98.35M，对照201.67M。资源较少不代表更快于所有baseline，也不代表精度全面领先。


本报告由固定权重完整TEST和随后独立计时生成；没有使用TEST选择权重、范围或微调参数。公共与CARLA结果分开，通用模型与CARLA微调模型分开。

- 七公共域共11970组；CARLA完整200组、缺相机150组（111组三目、39组双目），同一上相机参考。无tele、无额外传感器。
- 公共每域使用原真实2或4图和已登记参考。主图256×448；自研原生匹配512×896。共同像素版本从256×448放大，因此不额外获得高分辨率信息。baseline使用其原生匹配尺寸。
- 全部精度和计时FP32、TF32关闭。MVSAnywhere均开启官方快速代价体；所有适用ViT同样缓存冻结位置插值。自研未启用会引起少量选峰变化的可选浮点重排。
- MVSAnywhere同时报告原生标定启发式范围及共享TRAIN范围，后者与自研使用完全相同先验；首遍与一轮范围细化分别报告。不要逐域选择最有利baseline拼成一条结果。
- MAE/RMSE/AbsRel按全部有效预测像素加权；δ1/2/3分别为比例误差小于1.25/1.25²/1.25³的GT像素比例，缺失预测记失败。GT分母和帧数跨模型核对；不按预测置信度删难例。预测覆盖率不是多视图表面认证率。
- 公共域保留全部合法正深度GT；CARLA固定2–80m。scene_unit不是米，不跨单位平均绝对误差。深度定义与原数据协议一致，CARLA原始采集脚本仍不可核对。
- 本轮只比较单参考稠密深度。尚未进行完整四参考场景融合、点云F-score、占据IoU或车端测试；不能用单参考Hz冒充完整三维场景更新率。
- 速度由同一张空闲5090、batch1、VAL首中末3组、每组预热8次及轮转30次测得，含输入适配，另列格点转换；不含读盘/H2D。峰值显存另以单模型独占运行记录，allocated不包含CUDA驱动上下文。
- 新自研公共权重选自阶段3第15轮完整VAL最优，旧自研选自上一轮公共完整VAL；新CARLA训练220组、旧自研和既有MVSAnywhere训练66组，训练预算不同，不作纯架构归因。
- SimpleRecon为本地四目CARLA3000步权重，并非官方八目Hero权重；Fast-MVSNet为官方DTU权重。不同原始训练经历会影响域迁移，不能以此推断原论文上限。
- MVSAnywhere在部分公共测试场景可能有官方预训练暴露（研究记录101）；本地测试不是全域盲测或同预算纯架构比较。
- 缺相机时自研使用显式掩码；MVSAnywhere/Fast仅移除缺失槽，保持真实图像与参考标定不变；Simple固定四目权重不测缺相机集合。
- CARLA本轮使用全图有效2–80m像素，未额外裁历史rig空间ROI（x0–80/y±45/z−2–20）；因此只对照本轮同掩码重测，不能把旧1.120m直接搬进这张表。
- 完整帧和缺相机帧来自不同的自然采样时刻；缺相机集合误差较小不证明删除相机改善结果。这不是同帧受控丢相机消融。
- 上轮公共权重使用106的compact推荐版并启用相同spatial_layout；上轮CARLA权重仍保持其checkpoint内compact_sources关闭，仅启用spatial_layout。CARLA旧版较慢包含已知冗余参考源计算，不能解释为本轮重训改变了参数量或带来新学习算法加速。
- CARLA缺相机计时选取45组VAL中的首/中/末三组，三者恰好均为真实三目；该延迟不能标成整个双目/三目混合集合的时延分布。缺相机TEST精度仍覆盖全部150组。
