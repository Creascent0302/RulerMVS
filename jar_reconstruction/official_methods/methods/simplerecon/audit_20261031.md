# SimpleRecon：2026-10-31 独立源码与可运行性复核

本轮保留官方 Hero 的 Metadata + ResNet Matching 主模型，没有换成 dot-product 消融。CPU 完整图和独立官方源码前向通过；没有新增训练或精度结果。

## 固定来源

[ECCV 2022论文](https://arxiv.org/abs/2208.14743)；[官方代码](https://github.com/nianticlabs/simplerecon)，固定提交 `113b825084cc62166c6f5584d526650928127317`。图像先验 EfficientNetV2-S、抗混叠 ResNet18 匹配、64个对数候选、全部几何元数据拼接MLP、二维 `CVEncoder` 与 `DepthDecoderPP` 均保留。输出最高为RGB一半分辨率。

[2022-12-31官方修复](https://github.com/nianticlabs/simplerecon#-bug-fixes)涉及内参、几何翻转和投影掩码，本地提交包含修复。配套[新版八目Hero权重](https://drive.google.com/file/d/1hCuKZjEq-AghrYAmFxJs_4eeixIlP488/view)不能直接加载到四目MLP。本轮未下载该权重，独立对照使用同一份四目随机权重，不能称预训练精度复现。保留Niantic非商业许可证。

## 适配边界

官方八目与四目MLP输入宽度不同，按官方构造函数创建三源四目实例需要训练对应输入宽度，不得裁剪权重或复制图片。VKITTI2真实双目又是不同宽度，不能假定同一四目任务权重可联合处理N=2/4。它适合做相同四目数据训练后的二维网络对照，当前不宜当统一变相机数零样本主对照。

当前adapter拒绝缺RGB和任意像素孔洞。主表应明确完整四目共同子集，缺视图结果单列，不静默删模型失败像素。原生损失确有0.2权重多视角深度项；缺源GT时跳过必须披露。本轮独立稀疏案例证实“所有有效监督公式完全等价”的旧表述过宽：部分尺度空集合也会改变官方NaN行为，应按本条边界解释。

官方输出为相机Z-depth；直接加载ScanNet任务权重时还需遵守官方坐标/FOV说明。米制域与`scene_unit`分别评价。四目随机初始化管线可运行不等于得到有竞争力的训练后结果。

  official_methods/.venv/bin/python -m official_methods.tests.simplerecon_official_parity "$phase" \

  official_methods/tests/test_simplerecon_resume.py \
