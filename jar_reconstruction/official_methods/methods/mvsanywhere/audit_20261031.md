- 完整201,670,426参数网络在CPU、四目64×96、64候选下通过前向、五核心组有限非零梯度、一次优化、严格checkpoint重载。约807MB临时checkpoint写数据盘后删除。
- 独立未经修改的官方源码与adapter在新CARLA VAL一帧和一致合成场景各轮换4参考，144个原生张量逐值相同。原始代码与集成版本分进程加载，并使用同一完整Hero权重；只拦截初始化下载、重建尺寸相关解析网格。
- 官方快速向量化代价体路径另测一次，144个张量也逐值相同。慢/快路径各自与其官方实现比较，不宣称快慢之间浮点逐值相同。
- 密集深度、含天空密集深度、稀疏块的原版/本地总损失与预测梯度逐值相同；全空监督原版NaN、本地有限零，是明确扩展。
- 6 tests和4 subtests重新通过，包含源排序、标签隔离、优化器参数组等价和恢复训练；与组合测试不重复相加。

没有改核心网络/损失。`niantic_smoke.py`让临时权重随结果目录存放；`mvsanywhere_official_parity.py`增加官方快速路径测试支持。当前新CARLA只用于一帧无标签前向审计，不产生新精度结论。

## 数据与公平边界

官方源视图独立MLP可同权重支持不同N；当前公共adapter仍按配置检查N，拒绝缺RGB或任意像素孔洞。完整四目可直接使用，VKITTI2应配置真实N=2；缺图时需显式剔除真实缺相机并披露协议，不补零图伪装观测。

默认保留标定启发式/预测引导范围；共享TRAIN范围是另一个协议，要让所有方法得到相同范围信息，不能按TEST标签取范围。原生输出为Z-depth。推理不读取GT，训练标签范围扰动在eval被忽略。

主表区分首遍和一次细化，不能把首遍时间配细化精度；同卡、分辨率、精度、缓存、预热和同步均须一致，单参考和四参考总开销另列。本轮CPU管线总耗时不是5090网络速度，八卡V5仍在训练，未新测GPU速度。

官方任务预训练涉及项目公开域的数据集类别，需披露具体训练暴露，不能把所有本地TEST都称完全未见域；CARLA微调不称官方零样本。原论文RMVD和本地公开域/CARLA是不同协议。

## 复跑与证据

从`jar_reconstruction`执行：

```bash
official_methods/.venv/bin/python -m official_methods.tests.niantic_smoke \
  --method mvsanywhere --device cpu \
  --output runs/active/baseline_audit_20261031/niantic/mvsanywhere_cpu.json
for phase in prepare official adapter compare; do
  official_methods/.venv/bin/python -m official_methods.tests.mvsanywhere_official_parity "$phase" \
    --official-source /tmp/mvsanywhere_official_audit_20261013 \
    --config official_methods/methods/mvsanywhere/configs/audit_20261031.json \
    --output runs/active/baseline_audit_20261031/niantic/mvsanywhere_independent \
    --device cpu || break
done
```

独立官方目录来自固定提交完整克隆，本轮确认工作区无修改。丢失时需要重新取得原始官方代码，不能将集成目录伪装成独立参考。证据根目录`runs/active/baseline_audit_20261031/niantic`包括CPU报告、`mvsanywhere_independent/parity_report.json`、`mvsanywhere_independent_fast/parity_report.json`、`mvsanywhere_loss_parity.json`及日志；快速配置在同目录`mvsanywhere_fast.json`。

首次配置使用相对manifest，加载器按数据根拼接后报错，改成绝对路径后重跑成功，未自动改用合成数据。历史`carla_finetune.json`的66/25/200帧与旧训练结果只作2026-10-13记录，不能用于当前新CARLA评测。
