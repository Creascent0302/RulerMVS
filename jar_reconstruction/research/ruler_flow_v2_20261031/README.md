## 本轮解决什么

原细层每组已有三个精确匹配采样，但连续偏移主要由逐候选 `64→1` 头预测。本分支把组三点共同交给一个 **18,339 参数**的小网络，利用一次计算好的匹配证据预测局部连续修正。

- 保留原 96 个粗候选、四组×三点细候选、源视图/null 注意力和标尺。
- 保留原选面分数、候选身份、原连续偏移作为起点，以及原凸上采样。
- 三点特征与几何统计 `218→48` 形成缓存上下文；搜索区间交叠控制四邻域消息。
- 状态与两个时间条件通过 `58→48→48→3` 小头预测平均速度，默认一步输出。
- 真正使用 MeanFlow 的 JVP 平均速度目标，并保留真实起点监督。JVP 不穿过图像投影采样。
- 不新增质量评分头、不反复 warp、不把移动后的预测点冒充重新测得的观测。
- 同帧多参考可共享匹配编码；每个参考仍独立运行 ViT 和解码，不增加历史帧或传感器。

它仍不能直接恢复支持区间外的表面，也不能通过局部更新直接纠正错误的表面组选择。完整TEST显示公共粗层MAE只有一个域改善，细层六个域改善；初始候选瓶颈尚未解决。

## 短试时的速度与公平性（完整训练后的对照见上方报告）

同一RTX5090、FP32、TF32关闭、相同位置缓存，3帧×40次交替测量、每帧每方法10次预热。输入常驻GPU，包含完整编码和预测，不含读盘、预处理、传输及三维融合。四参考为实际四次输出，非单参考乘四。

| CARLA口径 | 原V2 | 新MeanFlow |
|---|---:|---:|
| 四目输入、单参考 | 31.366 ms | 32.470 ms |
| 四参考依次完整调用 | 124.802 ms | 129.729 ms |
| 四参考共享匹配编码 | 106.217 ms | 110.922 ms |
| 共享方式频率 | 9.415 Hz | 9.015 Hz |

新流场约增加1.1ms单参考成本。共享匹配编码使新模型比旧串行入口快约11%，但原模型也能使用相同优化，因此不能将它归功于Flow；同样共享时原V2仍更快。尚未达到四参考10Hz目标。没有在本次短试重新测MVSAnywhere。

真实3帧×4参考×18输出字段的共享与串行结果，对两个模型均逐位一致。测速结果见 `latency_public.json` 和 `latency_carla.json`。

## 文件与接口

| 文件 | 职责 |
|---|---|
| `field.py` | 三点证据上下文、几何邻域、平均速度头 |
| `model.py` | 独立模型、严格旧权重迁移、单/多参考推理 |
| `losses.py` | 可达cell责任、真实起点损失、Flow/MeanFlow目标 |
| `training.py` | 原成熟训练器的薄封装、新旧参数分组 |
| `prepare.py` | 独立配置、初始化迁移和数据曝光预算 |
| `pilot.py` | 固定短预算原结构/direct/MeanFlow对照 |
| `evaluation.py` | 新旧模型工厂适配，复用共同指标 |
| `after_training.py` | 训练完成后固定TEST与公平测速 |
| `latency.py` | 单参考及真实四参考共享/串行测速 |
| `run_full.sh` | 公共训练→CARLA适配→最终评测队列 |

Python输入沿用原 `inputs`，标签单独在 `targets`。输出仍为原生深度/有效性/置信度/支持信息；不伪造已验证占据。

```python
model.eval()
one = model(inputs, domain, reference=2)
four = model.forward_references(inputs, domain, references=[0, 1, 2, 3])
```

训练入口通过新架构ID `ruler_flow_v2`严格恢复，不得用旧 `PretrainingModel`直接吞掉新键。多参考共享API只用于eval，不跨帧缓存。

## 完整训练计划

从现有独立自研V2热启动，并非重新从零预训练。所有阶段连续训练，不在阶段间载入best回退。完整VAL按MAE、RMSE、AbsRel的原多域尺度归一化规则选择本次best；final另存。TEST不参与结构、超参数或checkpoint选择。

| 阶段 | 数据/轮数 | 可训练部分 | 主要学习率 |
|---|---|---|---|
| 公共1 | 七域完整1轮 | 新流场 | 1e-3 |
| 公共2 | 七域完整2轮 | 流场、原decoder、匹配FPN | 3e-4 / 1e-5 / 1e-5 |
| 公共3 | 七域完整8轮 | 上述、匹配骨干、ViT末四块 | 1e-4 / 5e-6 / 5e-6 / 5e-7 / 5e-8 |
| CARLA1 | 新四目497帧，6轮 | 流场、原decoder、匹配FPN | 1e-4 / 1e-5 / 5e-6 |
| CARLA2 | 同TRAIN，18轮 | 上述及匹配骨干 | 5e-5 / 5e-6 / 2e-6 / 2e-7 |

公共每轮覆盖42,598个唯一训练组，保留已有域重放配比和补齐，八卡每卡batch4，全局32；每轮1,670更新，11轮18,370更新，587,840次曝光。CARLA每轮16更新，24轮384更新、12,288次曝光；每台相机使用自己的GT，不使用tele。公共与CARLA分别保留权重。

先让零初始化新头适应，再以较低学习率联合已有表示，是保护成熟编码器的经验设计；具体轮数/学习率不是理论最优解。本次额外训练预算必须在最终比较中披露，不能把全部增益归因于新架构。
