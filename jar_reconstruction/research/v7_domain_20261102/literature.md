# V7 针对 ETH3D / CARLA 的方法调研与设计依据

日期：2026-11-02。本文是方案依据，不是新模型的实验结论。已阅读 research_memory.md 218–225，核对 V6Decoder、HierarchicalHandoff、transport_proposals、CandidateViewAttention 和 MixedDataset 的实际实现。

## 先否定过于简单的原因解释

植被会产生遮挡、重复纹理、细枝叶和混合像素，但不能把所有误差都归于植被：

- ETH3D 这批测试实际是灰度双目、约 6 cm 基线。去掉遮挡 GT 后，V6 MAE 仍为 2.0962 m，MVSAnywhere 细化为 0.9689 m，说明仅解决遮挡不能解释整个差距。具体场景贡献仍须由本轮诊断统计，不能从场景名称推断像素语义。
- CARLA V6 下参考已经在 MAE 和表面几何上优于 MVSAnywhere；上/左/右并不如此。这反对“植被出现就全部失败”的解释，提示观察方向、监督分布和候选读出都要隔离。
- 当前训练增强仅为逐相机 0.85–1.15 亮度增益，以及 15% 概率删除一个源相机（只在 N>2 时）；没有灰度、gamma、模糊、局部源遮挡或基线变化。这是可直接由代码确认的训练条件缺口，不等于已证明主因。
- V6 并未把所有场景拟合成平面。直接新建“非平面分支”缺乏现有证据，且容易增加时间。应先处理不可靠匹配如何影响读出、宽搜索如何转化成精确位置。

这些方法没有证明“ETH3D 的问题就是植被”。本轮应借鉴匹配与定位分工、不同空间频率处理、几何与外观随机化，而非按名称叠加模型。

## 首选：宽搜索与精确定位分开，保持既有候选预算

当前四族各三点，中心为粗预测，半径为

`h = clip(max(粗格半宽, 0.5 / |g|), h_min, h_max)`，其中 `g` 是特征像素/规范化深度单位的投影导数。**配置核对更正：本次正式V6的上下限为0.005和100（规范化深度单位）；0.05和8只是代码默认值，不是本轮实际配置。** 深度范围与候选合法性还受域级范围约束，不应把100直接解释为100米。

平行双目中 `|g|` 与 `f B / Z²` 成比例。远处或短基线会得到很宽的三点族；这不等于需要把三点的概率直接平均成表面位置。若 `μ = Σ p_j z_j`，则 `∂μ/∂s_j = p_j (z_j − μ)`。同样的概率误差在宽族中带来更大的深度偏移。上轮取消扩宽改善常见误差却损远尾，也说明不能简单把宽搜索删掉。

建议原型只改读出，不增加编码、投影、候选数或全局卷积：

1. 保留宽候选，用于判定当前中心是否选错、该转到哪一个族。
2. 组内定位同时提供当前深度均值、逆深度均值、原中心及赢家 offset，门控只依赖已计算的分数、候选相对跨度、有效源及源 null。输出仍是同一选定族内的连续位置，不跨族平均。
3. 初始门严格恢复 V6，以现有 V6 训练权重为独立起点；先冻结编码器，用相同 TRAIN 数据、预算与原 V6 继续训练对照。
4. 允许根据观测条件减小“读出位移”，但保留宽候选检出大错误的能力。更激进候选替换只在诊断证明供给不足后做。

逆深度均值 `Z_h = 1 / Σ(p_j / Z_j)` 在校正双目里对应平均视差，而深度均值对应平均米制位置。二者目标不同；由 Jensen 不等式 `Z_h ≤ Σp_jZ_j`，所以不能直接全局换成逆深度均值，再将远处低估误报成提高精度。应将其作为零初始化可选原型，检查过估/低估与分距离结果。对一般非平行相机，逆深度不是所有投影精确线性，实际候选仍必须精确投影。

这里新的组合假设是：标尺不只控制去哪里采样，还控制“这个概率误差应该允许造成多大位移”。它保留 V6 的候选族思想，区别于新增大体积/循环网络。可行性不等于新颖性或已达标，需要实验。

## 数据改造：优先提升观测覆盖，而非画出虚假的枝叶

### 第一层：零推理开销的外观扰动

- 共享灰度：同组所有视图使用同一灰度映射，仍保留三通道接口；rgb 与 matching_rgb 使用相同变换。
- 共享 gamma/对比度加少量逐相机差异；同一相机两种编码输入必须保持物理对应，不能独立产生冲突。
- 小幅异方差噪声、有限模糊和源局部遮挡。参考标签不因源遮挡而删除；显式缺图可以设置 mask，未知遮挡污染应保留 mask 来训练拒绝能力，两种条件分开记录。
- 保留未增强样本、各域重放和原目标，避免模型只适应灰度或过度忽略源图。比例是可检验超参数，不称理论最优。

### 第二层：只用 TRAIN 的几何一致再生成

给定 `I, Z, K, T`，反投影 `X = T_rig_from_cam (Z K⁻¹ u)`，生成新相机位姿后精确投影。采用 z-buffer 选近表面；对多源可见片合成、投影边缘冲突及空洞保留显式掩码。

- 短基线样本不应通过仅缩放 T 而保持 RGB 不变产生；那会变成错标定训练。
- 单视图合成不能恢复真正遮挡后的纹理，不能宣称增加真实场景几何。源图空洞可标缺失，但不能填上纹理后当成有效对应。
- 先选择现有 TRAIN 中有完整深度且几何一致的样本；基线在可控区间随机化，输出原深度单位并重算 K/T/有效区域。
- 合成后验证投影往返、遮挡处理、深度单位，检查重投影误差；与原样本混合训练，不替代全部真实多目证据。
- 面向不规则表面，可按 TRAIN 深度局部相对梯度与多层遮挡比例分桶抽样。它是几何难例采样，不能未经语义核验叫植被采样。对树叶纹理做二维粘贴但不给一致三维关系会破坏任务，不采用。

## 在保持优势前提下的实验次序

1. 先以既有 TEST 做误差归因，不用其结果挑训练超参数；CARLA 的新架构选择使用 TRAIN/VAL，ETH 不加入已被观察的 27 对进行微调后再称零样本。
2. 同 V6 起点，分开比较“原训练继续”“只增强”“只改读出”“增强+读出”；保持预算与种子。已知域用于重放，不通过域名在推理时选择独立作弊分支。
3. 各域完整 VAL 的 MAE/RMSE/AbsRel 与近中远分层必须同时检查；ETH 正式确认最好新增封存的场景，而不是重新选择已看过的那批权重。
4. 只有 net latency 计时证明增量在预算内，且共同完整 VAL 不存在实质回退，再启动新八卡训练。V6 checkpoint、源码快照、配置、测试清单保持独立。

“其他指标完全不变”无法由训练方法数学保证；可以设置明确升级门槛、保留 V6 并独立比较。训练期重放/自身教师约束可降低遗忘，部署仍单一模型，但这些是候选方案，本文没有将其写成已执行。

## 接到新分层诊断后新增的候选：缺证据时补充图像先验

主任务的新诊断指出：CARLA 某些参考的主要差距位于没有可投影源的区域，ETH 的差距随弱视差明显增大。这支持先测试“无可靠匹配时补充已有图像上下文”，并非必须新增植被专用表面表示。诊断原始数值以主任务的输出文件为准。

已新增独立 `prior.py::EvidencePrior`，默认 40,416 参数：四层各128维特征在原stride8对齐后拼接，512→64点卷积、GroupNorm、SiLU；并行深度可分离3×3卷积（dilation1和3）平均后残差相加，64→96零初始化输出粗候选分数修正。不新增ViT、图像匹配、重投影或迭代。零初始化时严格输出零，原V6保留。

门由已有源拒绝质量 `n` 与尺度化导数 `ρ²=Z²Σw|g|²` 构造：`gate=n+(1−n)τ²/(τ²+ρ²)`。`τ=.5`特征像素只是预先给定的可检验默认值。弱视差/无源时允许较多先验修正，强证据时软减弱，但不保证强匹配区域完全不变。统计停止梯度，防止模型通过增大null来增大这条旁路。它不是额外测量，更不是表面可见性认证。

注意潜在局限：96通道直接对应当前候选索引，原型没有额外输入绝对搜索范围，可能学习域相关的相对深度。门的单位一致性不等于整个图像先验的物理尺度等变。如果实验发现变范围泛化退化，才考虑已知范围/焦距条件化，不能先假定无需训练即可泛化。

实际 CPU 命令 `official_methods/.venv/bin/python -m pytest -q research/v7_domain_20261102/test_prior.py`：3 passed，1.78秒。验证零初始化、第一/二次更新梯度、缺证据有限输出、门的单位换算与质量顺序、checkpoint严格重载。GPU性能、完整模型预测和真实精度尚未由这个模块测试证明；由主任务继续集成和测试。
