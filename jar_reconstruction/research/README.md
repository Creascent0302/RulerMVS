# 研究代码索引

独立实验不自动接入默认模型。开始新实验前先读 [research_memory.md](../docs/research_memory.md)，完成后追加结论。

| 目录 | 保留用途 |
|---|---|
| `ruler_flow_v2_20261031/` | V4平均流研究：全量训练及两套完整TEST已完成，局部受益但未替换默认；报告见docs/v4_evaluation_20261031.md |
| `ruler_flow_20261030/` | 最新局部条件 Flow / 同结构 direct 对照，完整原型、测试、配置和全部结果保留 |
| `role_fusion_20261030/` | 最新按职责融合和候选质量传递，亦被 Flow 复用 |
| `early_geometry_20261030/` | 早期几何原型及新实验仍调用的训练/诊断工具 |
| `near_evidence_20261030/` | 多实验共享的采样、验证、参数哈希及近距诊断 |
| `v2_restart_20261029/` | 最新 V2 公共全量训练＋新 CARLA 微调、八卡启动与测试 |

部分旧目录是依赖，不能仅按日期删除。最近两轮 `role_fusion`、`ruler_flow` 的原始代码与所有结果保留。更早试验被清理的仅为清单中列出的可再生成缓存、未采用原型权重及冒烟副本；其配置、日志和指标仍在数据盘，可查 [清理审计](../docs/project_cleanup_20261031.md)。

所有配置内已有输出都是历史已完成运行。新实验应改为新目录，不覆盖旧结果。采用一个新模块前，应比较冻结起点、同预算续训、同预算新结构，而不是仅与旧 checkpoint 比较。
